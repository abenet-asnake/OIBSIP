## Objective

The objective of this project is to build a machine learning model that predicts product sales based on advertising expenditures in TV, Radio, and Newspaper media.

Advertising Dataset

- NumPy
- Matplotlib
- Seaborn

- Google Colab

## Analysis Performed

- Data Cleaning
- Exploratory Data Analysis
- Correlation Analysis
- Feature Selection
- Linear Regression Modeling
- Model Evaluation
- Sales Prediction

## Key Findings

- TV advertising has the strongest impact on sales.
- Radio advertising positively influences sales.
- Newspaper advertising has the least impact.
- The model predicts sales with high accuracy.

## Business Recommendations

- Increase investment in TV advertising.
- Optimize radio marketing campaigns.
- Reevaluate newspaper advertising budgets.
- Use data-driven strategies for future campaigns.
