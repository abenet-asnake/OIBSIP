## Objective

The objective of this project is to identify customer groups based on annual income and spending score using K-Means Clustering.

## Dataset

Mall Customers Dataset

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Google Colab

## Analysis Performed

- Data Cleaning
- Exploratory Data Analysis
- Customer Demographics Analysis
- Correlation Analysis
- Elbow Method
- K-Means Clustering
- Customer Segmentation Visualization

## Key Findings

- Five distinct customer segments were identified.
- Premium customers were separated successfully.
- Spending patterns differ across customer groups.
- Income and spending information can help businesses target customers.

## Business Recommendations

- Create customer-specific marketing strategies.
- Focus on premium customer retention.
- Improve engagement with low-spending customers.
- Develop personalized offers.
